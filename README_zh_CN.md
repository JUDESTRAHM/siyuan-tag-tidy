# 标签整理：重复与清理

找出其实是同一个标签的重复标签，并一键合并。免费开源（MIT），无遥测，除你自己的思源内核外不发起任何网络请求。

## 功能
- 点击顶栏的标签图标（或运行命令“打开标签整理”）。
- 找出疑似重复标签：`#Project#` 与 `#project#`、`#my-tag#` 与 `#my_tag#`、`#todo#` 与 `#todos#`。匹配时忽略大小写、空格、连字符、下划线和复数 s，并逐级处理路径（`work/Alpha` 与 `Work/alpha`）。
- 建议保留使用最多的写法（次数相同取较短者），一键合并。合并使用思源自带的标签重命名，所有使用该标签的文档都会更新。
- 列出仅使用一次的标签（常为拼写错误）和最常用的标签。
- 一键复制以上内容的 Markdown 报告。

提示：合并会修改文档中的标签，建议先试一组。重命名父标签时，其子标签也会一起改名。

## 安装
集市 → 插件，搜索“标签整理”。

## 开发
`npm install`，然后 `node build.mjs` 将 `src/plugin.js` 打包为 `index.js`。`npm test` 运行测试。`node test/realkernel.mjs` 针对本机 6806 端口的内核运行。

## 免费版与专业版
以上功能永久免费。专业版为可选的一次性授权（12 美元）：一键合并所有建议（需确认），以及将全部标签、使用次数和建议合并目标导出为 CSV。在插件窗口点击“获取授权密钥”，付款一次后把密钥粘贴到授权密钥框即可。密钥在本机校验（Ed25519 签名），不联网、无需账号、无遥测。
